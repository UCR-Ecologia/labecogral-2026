Laboratorio 08: efectos aleatorios — guía para la persona instructora

Respuestas sugeridas

Caso 1. Muestreo anidado

Estructura sugerida: interceptos aleatorios para sitio y parcela dentro de sitio, por ejemplo:

crecimiento ~ tratamiento + (1 | sitio/parcela)

Las plántulas de una misma parcela comparten condiciones locales y las parcelas están anidadas en sitios. El tratamiento se asigna dentro de las parcelas.

Caso 2. Medidas repetidas

Estructura sugerida: intercepto aleatorio para plántula; una pendiente aleatoria de tiempo puede ser apropiada si el diseño y los datos la respaldan:

altura ~ tratamiento * semana + (1 + semana | plantula)

Las mediciones semanales de una plántula no son independientes. La interacción tratamiento por semana estima la diferencia en tasa de crecimiento entre tratamientos.

Caso 3. Diseño en bloques

Estructura sugerida: intercepto aleatorio para bloque:

crecimiento ~ tratamiento + (1 | bloque)

Las parcelas de un mismo bloque comparten humedad y condiciones de base, y la comparación de tratamientos se hace dentro de cada bloque. Con solo 10 bloques, también puede ser defendible tratar bloque como efecto fijo si la inferencia se limita a esos bloques específicos.

Caso 4. Efectos de lote

Estructura sugerida: intercepto aleatorio para lote:

crecimiento ~ tratamiento + (1 | lote)

Las plántulas de cada corrida comparten condiciones de invernadero. Ambos tratamientos deben aparecer en cada lote para evitar confundir tratamiento con corrida. Con seis lotes, la varianza entre lotes puede estimarse con poca precisión; un efecto fijo puede ser preferible si interesan esos seis lotes particulares.

Caso 5. Predictor medido a nivel de sitio

En el caso, se mide la altura de cada planta al inicio y al final de la estación, y se calcula un único incremento de altura por planta. Para ese análisis de incrementos, una estructura inicial es:

crecimiento ~ cobertura + (1 | sitio)

La cobertura del dosel varía entre los 12 sitios, no entre las 120 plantas. Las plantas de un mismo sitio comparten condiciones y no son réplicas independientes para el predictor cobertura. El intercepto aleatorio de sitio representa la correlación entre plantas del mismo sitio. El efecto de cobertura se informa principalmente por las diferencias entre los 12 sitios.

No se necesita agregar (1 | planta) cuando cada planta aporta un solo valor de incremento: la variación entre plantas queda en el error residual. Aunque la altura se midió dos veces, el análisis propuesto utiliza un único resultado calculado por planta. Si en cambio se modelaran las dos mediciones de altura como observaciones separadas, estas serían repetidas dentro de cada planta y sí se podría incluir un intercepto de planta anidado en sitio:

crecimiento ~ cobertura + (1 | sitio/planta)

En la notación de modelos mixtos, sitio/planta representa un efecto de sitio y otro de planta dentro de sitio. El orden inverso, planta/sitio, no representa esa jerarquía.

La comparación conceptual relevante es entre un modelo que ignora los sitios, crecimiento ~ cobertura, y el modelo que representa su agrupamiento, crecimiento ~ cobertura + (1 | sitio). No se trata de comparar un modelo con efecto aleatorio de planta contra otro con efectos aleatorios de planta y sitio.

Respuestas a las preguntas de discusión

  1. Unidad experimental: la unidad asignada independientemente al tratamiento. En los casos 1, 2 y 4 es la plántula; en el caso 3 es la parcela. La unidad de observación indica dónde se mide la respuesta, pero mediciones repetidas de la misma unidad experimental no crean nuevas unidades independientes.
  2. Dependencia: puede surgir entre plántulas de una misma parcela o sitio, entre parcelas de un mismo bloque, entre plantas de un mismo lote y entre mediciones de un mismo individuo. Los efectos aleatorios deben corresponder a agrupamientos presentes en el diseño y relevantes para la inferencia.
  3. Efecto del tratamiento: representa la diferencia entre tratamiento y control, condicionada al resto del modelo y en la escala del enlace para un modelo lineal generalizado. En medidas repetidas, la interacción tratamiento-tiempo evalúa si cambia la tasa de crecimiento.
  4. Omitir el agrupamiento: el modelo puede tratar observaciones correlacionadas como si fueran independientes, exagerando el tamaño efectivo de muestra y produciendo incertidumbre demasiado pequeña.

Puntos para enfatizar

  • La asignación balanceada no elimina la dependencia debida a bloques, sitios, lotes o mediciones repetidas.
  • El número de niveles independientes de un predictor importa. Tener muchas plantas en pocos sitios no sustituye muestrear más sitios para estimar una relación a nivel de sitio.
  • La estructura de muestreo y la unidad de asignación del tratamiento son conceptos distintos: las plántulas pueden recibir el tratamiento individualmente y aun así compartir condiciones de sitio o parcela.
