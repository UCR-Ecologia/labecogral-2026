Datos de las colonias de coral

Después de algunas semanas cálidas por el Niño, se evalúan colonias de corales en varios sitios:

  • blanqueado = 0: sana o recuperada
  • blanqueado = 1: blanqueada o muerta
  • Predictor: temperatura promedio durante las últimas dos semanas

La unidad de observación es una colonia individual.

Proceso

  • Hay dos posibilidades: sano (\(0\)) o blanqueado (\(1\)).
  • Valores como ‘mediosano’ o ‘pocoblanqueado’ no son posibles.

Que nos indica esto sobre la distribucion matematica con cual se podria generar este tipo de datos?

Se pueden generar con una distribuucion Normal? O necesitamos otra distribucion?

¿Por qué no un modelo lineal?

Un modelo lineal supone una respuesta continua y no es limitada entre 0 y 1:

\[ Y_i \sim \mathrm{Normal}(\mu_i, \sigma^2), \qquad \mu_i = \beta_0 + \beta_1 x_i. \]

Para blanqueado, esto falla porque:

  • solo existen \(0\) y \(1\);
  • una recta puede predecir valores menores que \(0\) o mayores que \(1\);
  • la variabilidad cambia con la probabilidad esperada.

Distribuciones comunes

El proceso Bernoulli

Para cada colonia:

\[ Y_i \sim \mathrm{Bernoulli}(p_i). \]

  • \(p_i\): probabilidad de blanqueamiento
  • \(\operatorname{Var}(Y_i) = p_i(1-p_i)\)
  • La variabilidad es mayor cerca de \(p_i = 0.5\)

Modelo generativo

Un modelo generativo describe un proceso posible para producir los datos:

  1. Medimos la temperatura promedio de las últimas dos semanas para una colonia.
  2. Esa temperatura determina una probabilidad de blanqueamiento, \(p_i\).
  3. Generamos un resultado: \(Y_i=1\) con probabilidad \(p_i\), o \(Y_i=0\) con probabilidad \(1-p_i\).
  4. Repetimos el proceso para muchas colonias.

El modelo no predice que una colonia estará “0.37 blanqueada”; predice la probabilidad de que esté blanqueada.

Simulaciones del modelo generativo

En cada simulación, muestreamos 100 colonias y calculamos la proporción observada de blanqueamiento.

  • La proporción observada varía entre muestras repetidas.
  • Con \[p=0.04\], las proporciones se concentran mucho más que con \[p=0.40\].

La variabilidad depende de \(p\)

GLM binomial con enlace logit

La respuesta sigue una distribución Bernoulli; la relación con el predictor es lineal en la escala de log-odds:

\[ \operatorname{logit}(p_i) = \log\left(\frac{p_i}{1-p_i}\right) = \beta_0 + \beta_1\,\mathrm{temperatura}_i. \]

  • El modelo estima probabilidades entre \(0\) y \(1\).
  • La pendiente es constante en log-odds, no en probabilidad.

Ajustar el modelo

modelo_binomial <- glm(
  blanqueado ~ temperatura,
  family = binomial(link = "logit"),
  data = corales
)

Predicciones en escala biológica

predict() devuelve log-odds por defecto. plogis() los convierte a probabilidades.

predictor_30 <- predict(
  modelo_binomial,
  newdata = data.frame(temperatura = 30)
)

plogis(predictor_30)
        1 
0.8999043

Comunicar el resultado

En vez de reportar solamente log-odds:

  • Reportar probabilidades predichas a temperaturas relevantes.
  • Mostrar incertidumbre con intervalos de confianza.
  • Conectar el patrón con riesgo de blanqueamiento.

Ejemplo: “La probabilidad predicha de blanqueamiento aumenta marcadamente a medida que aumenta la temperatura promedio.”

Otras distribuciones para GLM

Además de la binomial, existen otras distribuciones que se pueden usar en GLM según la naturaleza de la variable respuesta:

  • Poisson con enlace log: para conteos de eventos (0, 1, 2, …).
  • Negativa binomial con enlace log: para conteos sobredispersos.
  • Gamma con enlace inverso: para variables continuas positivas.
  • Multinomial con enlace logit: para variables categóricas con más de dos niveles.

El modelo lineal es un caso especial de GLM con distribución normal y enlace identidad.

Resumen

La distribución se elige según la variable respuesta.

  • Continua: modelo lineal con distribución normal.
  • \(0/1\): GLM binomial/Bernoulli con enlace logit.
  • El resultado se interpreta mejor como una probabilidad predicha.
